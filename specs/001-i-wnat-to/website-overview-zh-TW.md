# 台灣茶葉電商網站 - 實作後網站概覽

## 🌐 網站整體架構

這是一個**單頁式**茶葉展示與銷售網站，採用現代化的技術堆疊：
- **前端**：React 18 (使用 Vite 建置)
- **後端**：Python FastAPI
- **資料庫**：MongoDB

## 🎯 實際使用情境

### 情境一：顧客瀏覽購買
```
1. 顧客打開網站 → 看到精美的茶葉首頁
2. 捲動頁面 → 瀏覽「綠茶」、「烏龍茶」等分類
3. 點擊導航「紅茶」→ 平滑跳轉到紅茶區塊
4. 閱讀「日月潭紅茶」的詳細資訊
   - 看到產地：南投魚池
   - 風味描述：果香、蜜香、口感醇厚
   - 沖泡建議：90°C、3-5 分鐘
   - 價格：NT$ 650
5. (未來功能) 加入購物車、結帳
```

### 情境二：管理員上架新茶
```
1. 管理員打開 /admin 頁面
2. 輸入帳密登入 (admin@taiwantea.com)
3. 點擊「新增茶葉產品」
4. 填寫表單：
   - 產品名稱：梨山高冷茶
   - 分類：烏龍茶
   - 描述：來自海拔 2000 公尺...
   - 價格：1800
   - 上傳照片：tea-lishan.jpg (3.2MB)
5. 點擊「儲存產品」
6. 系統自動：
   - 壓縮圖片 → 轉 WebP
   - 產生縮圖
   - 存入 MongoDB
7. ✅ 完成！5 秒內前台網站顯示新產品
```

## 📊 技術特點

### 前端 (React)
- **元件化設計**：ProductCard、CategorySection、Navigation
- **狀態管理**：React Context API
- **路由**：React Router (/ 和 /admin)
- **API 通訊**：Axios
- **樣式**：CSS Modules (避免樣式衝突)

### 後端 (FastAPI)
- **非同步處理**：Motor (MongoDB 非同步驅動)
- **資料驗證**：Pydantic
- **認證授權**：JWT + bcrypt
- **API 文檔**：自動產生 Swagger UI

### 資料庫 (MongoDB)
```
Collections:
├── products (茶葉產品)
│   ├── 名稱、分類、描述
│   ├── 價格、圖片 URL
│   └── 建立/更新時間
│
├── categories (茶葉分類)
│   ├── ID: green-tea, black-tea...
│   └── 顯示順序
│
└── admins (管理員)
    ├── 信箱、密碼 hash
    └── 最後登入時間
```

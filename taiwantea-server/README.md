# TAIWANTEA Server Management Scripts

This directory contains shell scripts for managing the TAIWANTEA development environment.

## Prerequisites

Before using these scripts, ensure you have:

1. **MongoDB** - Running on `localhost:27017` (or Docker container)
2. **Python 3.10+** - With virtual environment (optional but recommended)
3. **Node.js 18+** - For the frontend
4. **Dependencies installed**:
   - Backend: `pip install -r backend/requirements.txt`
   - Frontend: `npm install` in `frontend/` directory

## Quick Start

### Start Everything

```bash
./taiwantea-server/start_all.sh
```

This will:
- Start the backend API on port 8585
- Start the frontend dev server on port 5173
- Display URLs for accessing the application

### Check Status

```bash
./taiwantea-server/status_all.sh
```

Shows the status of all services, including:
- Process IDs
- Health check results
- Access URLs
- Available commands

### Stop Everything

```bash
./taiwantea-server/stop_all.sh
```

Gracefully stops both backend and frontend services.

## Logs

Logs are stored in the `logs/` subdirectory:

| Log File | Description |
|----------|-------------|
| `api.log` | Backend API standard output |
| `error.log` | Backend API errors |
| `frontend.log` | Frontend dev server output |

View logs in real-time:
```bash
# Backend logs
tail -f ./taiwantea-server/logs/api.log

# Backend errors
tail -f ./taiwantea-server/logs/error.log

# Frontend logs
tail -f ./taiwantea-server/logs/frontend.log
```

## Process Management

The scripts use PID files to track running processes:

- `taiwantea_api.pid` - Backend API process ID
- `taiwantea_frontend.pid` - Frontend process ID

These files are automatically created when services start and removed when they stop.

## MongoDB Setup

The backend requires MongoDB to be running. You have two options:

### Option 1: Docker (Recommended)

Start MongoDB using Docker Compose:
```bash
cd /home/datavan/METROPIA/TAIWANTEA
docker compose up -d mongodb
```

Stop MongoDB:
```bash
docker compose down mongodb
```

### Option 2: Local MongoDB

If you have MongoDB installed locally:
```bash
# Start MongoDB (Ubuntu/Debian)
sudo systemctl start mongod

# Or on other systems
sudo service mongodb start
```

The backend is configured to connect to `mongodb://localhost:27017/taiwantea` by default.

## Configuration

### Backend (.env)

The backend configuration is in `backend/.env`:

```env
# Database
MONGODB_URL=mongodb://localhost:27017/taiwantea

# Security (auto-generated secure key)
SECRET_KEY=<auto-generated-32-char-key>

# CORS
ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173

# Environment
ENVIRONMENT=development
```

### Frontend (.env)

The frontend configuration is in `frontend/.env`:

```env
VITE_API_URL=http://localhost:8585
```

## Troubleshooting

### Backend won't start

1. **Check MongoDB is running:**
   ```bash
   docker ps | grep mongo
   # OR
   systemctl status mongod
   ```

2. **Check port 8585 is not in use:**
   ```bash
   lsof -i:8585
   ```

3. **View error logs:**
   ```bash
   tail -f ./taiwantea-server/logs/error.log
   ```

### Frontend won't start

1. **Check node_modules are installed:**
   ```bash
   ls frontend/node_modules
   ```

2. **Check port 5173 is not in use:**
   ```bash
   lsof -i:5173
   ```

3. **View frontend logs:**
   ```bash
   tail -f ./taiwantea-server/logs/frontend.log
   ```

### Health check fails

If the backend starts but health check fails:

1. **Verify MongoDB connection** - Check that MongoDB is accessible at the configured URL
2. **Check error logs** - Look for startup errors in `logs/error.log`
3. **Wait a moment** - The backend may still be initializing
4. **Try manual health check:**
   ```bash
   curl http://localhost:8585/api/health
   ```

### Processes won't stop

If a service won't stop gracefully:

```bash
# Force kill backend
lsof -ti:8585 | xargs kill -9

# Force kill frontend
lsof -ti:5173 | xargs kill -9
```

## Development Workflow

Typical development workflow:

```bash
# 1. Start MongoDB (if not already running)
docker compose up -d mongodb

# 2. Start all services
./taiwantea-server/start_all.sh

# 3. Seed database (first time only)
cd backend
python src/scripts/seed_data.py
cd ..

# 4. Check everything is running
./taiwantea-server/status_all.sh

# 5. During development, restart as needed
./taiwantea-server/restart.sh          # Backend only
./taiwantea-server/restart_frontend.sh # Frontend only
./taiwantea-server/restart_all.sh      # Both services

# 6. When done, stop all services
./taiwantea-server/stop_all.sh
```

## Script Features

All scripts include:

- **Color-coded output** - Green for success, red for errors, yellow for warnings, blue for info
- **Timestamps** - All messages include timestamps
- **Health checks** - Verify services are responding
- **Graceful shutdown** - Try SIGTERM before SIGKILL
- **Process validation** - Check for stale PID files
- **Automatic setup** - Copy .env.example if .env is missing
- **Dependency checks** - Verify directories and files exist

## Production Deployment

These scripts are designed for **development only**. For production:

1. Use the Docker deployment: `docker-compose.production.yml`
2. See `DEPLOYMENT.md` for production setup
3. Configure proper MongoDB authentication
4. Use environment-specific secrets
5. Set up reverse proxy (nginx)
6. Configure SSL/TLS certificates

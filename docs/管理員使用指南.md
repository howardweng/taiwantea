## 1. 圖片上傳規範

### 📸 產品圖片標準規格

| 項目 | 規格 |
|------|------|
| **圖片尺寸** | **1200 × 1200 像素（正方形）** |
| **檔案格式** | **JPG** |
| **壓縮品質** | **80-85%** |
| **檔案大小** | **150-300 KB** |
| 最大檔案 | 5 MB（系統上限）|
| 色彩空間 | sRGB |
| 解析度 | 72 DPI |

<img src="screenshots/customer-product-card.png" alt="產品圖片顯示在產品卡片上" width="400">

---

### ✅ 拍攝要點

1. **光線充足** - 使用自然光，避免陰影
2. **背景簡潔** - 純白或淺色背景
3. **商品居中** - 佔畫面 70-80%
4. **清晰對焦** - 確保細節清楚

---

### 📋 上傳檢查清單

- [ ] 1200×1200 像素正方形
- [ ] JPG 格式
- [ ] 150-300 KB 檔案大小
- [ ] 背景乾淨簡潔
- [ ] 商品居中且清晰

---

### 🖼️ 系統自動處理

上傳一張圖片，系統自動產生：
- **完整尺寸** - 點擊放大檢視
- **縮圖** - 商品網格展示
- **小圖** - 行動裝置使用

所有圖片自動上傳到媒體伺服器 (mediaserver.frrut.com)。

## 4. 介紹區塊編輯器

### 📝 功能概述

介紹區塊編輯器是首頁的主要內容編輯區，支援豐富的文字格式化和圖片編輯功能。

<img src="screenshots/admin-intro-section-editor.png" alt="介紹區塊編輯器" width="600">

---

### ✏️ 文字格式化功能

編輯器工具列提供以下格式化選項：

| 功能 | 說明 |
|------|------|
| **標題** | 選擇 H1、H2、H3 或一般文字 |
| **粗體** | 加粗文字（快捷鍵：Ctrl+B）|
| **斜體** | 斜體文字（快捷鍵：Ctrl+I）|
| **底線** | 為文字加底線（快捷鍵：Ctrl+U）|
| **刪除線** | 在文字上加刪除線 |
| **文字顏色** | 更改文字顏色 |
| **背景顏色** | 為文字添加背景色 |
| **對齊** | 靠左、置中、靠右、左右對齊 |
| **清單** | 有序清單（編號）或無序清單（項目符號）|
| **連結** | 插入超連結 |
| **圖片** | 上傳並插入圖片 |
| **清除格式** | 移除所有格式 |

---

### 🖼️ 圖片編輯功能

#### 貼上圖片

1. 複製圖片到剪貼簿（截圖或從檔案總管複製）
2. 在編輯器中點擊要插入圖片的位置
3. 按下 **Ctrl+V**（Windows）或 **Cmd+V**（Mac）貼上圖片
4. 圖片會自動上傳並插入到游標位置
5. 支援格式：JPG、PNG、GIF、WebP
6. 檔案大小上限：5 MB

**提示：**
- 可直接貼上螢幕截圖
- 可從檔案總管複製圖片檔案後貼上
- 無需先儲存截圖檔案，直接貼上即可

---

#### 調整圖片大小

1. **點擊圖片** - 圖片四個角會出現藍色調整點
2. **拖曳角落** - 拖曳任一角落可等比例縮放圖片
3. **顯示尺寸** - 調整時會顯示當前圖片尺寸

**技巧：**
- 建議圖片寬度不超過編輯器寬度（避免破版）
- 等比例縮放可保持圖片清晰度

---

#### 調整圖片位置

1. **選取圖片** - 點擊要調整的圖片
2. **使用對齊按鈕** - 點擊工具列的對齊按鈕
   - **靠左對齊** - 圖片靠左顯示
   - **置中對齊** - 圖片居中顯示
   - **靠右對齊** - 圖片靠右顯示

---

### 👀 所見即所得（WYSIWYG）

編輯器中的顯示效果會**完全一致**地呈現在客戶前台：

- ✅ **文字格式** - 粗體、顏色、標題等格式完全相同
- ✅ **段落間距** - 行距和段落間距保持一致
- ✅ **圖片大小** - 您調整的圖片尺寸會精確顯示
- ✅ **圖片位置** - 左對齊、置中或右對齊完全相同
- ✅ **整體排版** - 編輯器中看到什麼，前台就顯示什麼

**重要提示：**
編輯完成後請點擊「儲存變更」按鈕，變更才會生效。

---

### 💡 編輯建議

1. **先寫內容，再調格式** - 避免過度格式化影響可讀性
2. **適度使用顏色** - 過多顏色會顯得雜亂
3. **圖片適當大小** - 太大會影響載入速度，太小看不清楚
4. **對齊一致性** - 建議圖片都使用相同對齊方式（例如都置中）
5. **定期儲存** - 編輯過程中定期點擊「儲存變更」

---

### ⚙️ 按鈕設定

編輯器下方可設定客戶前台顯示的行動呼籲（CTA）按鈕：

- **按鈕文字** - 設定按鈕上顯示的文字（例如：於蝦皮賣場購買）
- **按鈕連結** - 自動使用「網站設定」中的蝦皮商店網址
- **啟用狀態** - 勾選「啟用介紹區塊」才會在前台顯示

## 5. 技術維護記錄

### 🐛 已修復問題

#### 產品網格顯示不一致（2025年11月1日）

**問題描述：**
烏龍茶分類的產品卡片顯示尺寸異常，比其他分類的產品卡片更寬，導致第4欄商品被切斷。

**技術分析：**
- 當分類中有**8個產品**（剛好填滿4欄×2列）時，觸發瀏覽器CSS Grid渲染錯誤
- 烏龍茶區塊的欄寬被錯誤計算為 463px（應為 319px）
- 造成水平溢位：1912px（實際寬度）> 1336px（容器寬度）

**修復方式：**
修改 CSS Grid 樣板定義：
```css
/* 修改前 */
grid-template-columns: repeat(4, 1fr);

/* 修改後 */
grid-template-columns: repeat(4, minmax(0, 1fr));
```

**修復結果：**
- ✅ 所有分類的產品卡片寬度統一為 319px
- ✅ 支援任意數量的產品（1個、8個、20個以上皆正常）
- ✅ 保留交替背景色設計

**影響範圍：**
客戶前台 - 所有產品分類區塊

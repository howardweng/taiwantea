## 1. 圖片上傳規範

### 📸 產品圖片標準規格

| 項目 | 規格 |
|------|------|
| **圖片尺寸** | **1200 × 1200 像素（正方形）** |
| **檔案格式** | **JPG** |
| **壓縮品質** | **80-85%** |
| **檔案大小** | **150-300 KB** |
| 最大檔案 | 5 MB（系統上限）|
| 色彩空間 | sRGB |
| 解析度 | 72 DPI |

<img src="screenshots/customer-product-card.png" alt="產品圖片顯示在產品卡片上" width="400">

---

### ✅ 拍攝要點

1. **光線充足** - 使用自然光，避免陰影
2. **背景簡潔** - 純白或淺色背景
3. **商品居中** - 佔畫面 70-80%
4. **清晰對焦** - 確保細節清楚

---

### 📋 上傳檢查清單

- [ ] 1200×1200 像素正方形
- [ ] JPG 格式
- [ ] 150-300 KB 檔案大小
- [ ] 背景乾淨簡潔
- [ ] 商品居中且清晰

---

### 🖼️ 系統自動處理

上傳一張圖片，系統自動產生：
- **完整尺寸** - 點擊放大檢視
- **縮圖** - 商品網格展示
- **小圖** - 行動裝置使用

所有圖片自動上傳到媒體伺服器 (mediaserver.frrut.com)。

## 4. 產品管理

### 🖼️ 多圖上傳功能

產品現在支援上傳**最多 6 張圖片**，讓顧客從不同角度查看商品。

---

#### 📤 上傳圖片

1. **新增商品** 或 **編輯現有商品** - 進入產品表單
2. **找到「商品圖片」區塊** - 表單中部位置
3. **點擊「+」上傳卡片** - 選擇要上傳的圖片
4. **重複上傳** - 最多可上傳 6 張圖片

<img src="screenshots/admin-product-multi-image-upload.png" alt="產品多圖上傳" width="600">

**支援格式：**
- JPG, PNG, GIF, WebP
- 最大檔案大小：5 MB
- 建議尺寸：1200×1200 像素（正方形）

---

#### 🎯 第一張圖片 = 主圖

- **第一張圖片**會自動成為產品的**主圖**
- 主圖會顯示在產品列表、產品卡片上
- 主圖會標示「主圖」標籤

---

#### ⬅️ ➡️ 調整圖片順序

使用**左右箭頭**按鈕調整圖片順序：

1. **點擊圖片上的 ← 按鈕** - 將圖片向左移動（順序提前）
2. **點擊圖片上的 → 按鈕** - 將圖片向右移動（順序延後）
3. **調整主圖** - 將想要的圖片移到最左邊（第一位）即可

**範例：**
```
圖片順序：[1] [2] [3] [4]
點擊 [3] 的 ← 按鈕後
新順序：  [1] [3] [2] [4]
```

---

#### 🗑️ 刪除圖片

1. **滑鼠移到圖片上** - 會顯示控制按鈕
2. **點擊右上角的 ✕ 按鈕** - 刪除圖片
3. **確認刪除** - 圖片會立即從列表移除

**注意：**
- 至少需保留 1 張圖片
- 刪除後順序會自動調整

---

#### 👀 客戶端顯示

上傳的多張圖片會在**產品詳情頁**顯示為：

- **主圖區** - 顯示當前選中的圖片（大圖）
- **縮圖列** - 顯示所有圖片的縮圖，可點擊切換
- **圖片計數** - 顯示 "3 / 5"（當前第3張，共5張）

## 6. 技術維護記錄

### 🐛 已修復問題

#### 產品網格顯示不一致（2025年11月1日）

**問題描述：**
烏龍茶分類的產品卡片顯示尺寸異常，比其他分類的產品卡片更寬，導致第4欄商品被切斷。

**技術分析：**
- 當分類中有**8個產品**（剛好填滿4欄×2列）時，觸發瀏覽器CSS Grid渲染錯誤
- 烏龍茶區塊的欄寬被錯誤計算為 463px（應為 319px）
- 造成水平溢位：1912px（實際寬度）> 1336px（容器寬度）

**修復方式：**
修改 CSS Grid 樣板定義：
```css
/* 修改前 */
grid-template-columns: repeat(4, 1fr);

/* 修改後 */
grid-template-columns: repeat(4, minmax(0, 1fr));
```

**修復結果：**
- ✅ 所有分類的產品卡片寬度統一為 319px
- ✅ 支援任意數量的產品（1個、8個、20個以上皆正常）
- ✅ 保留交替背景色設計

**影響範圍：**
客戶前台 - 所有產品分類區塊

#### 產品多圖與富文本功能（2025年11月1日）

**新增功能：**
- ✅ 產品支援上傳最多 6 張圖片
- ✅ 圖片可使用左右箭頭調整順序
- ✅ 第一張圖片自動成為主圖
- ✅ 產品詳情頁顯示圖片輪播（縮圖導航）
- ✅ 富文本編輯器支援格式化文字、圖片、列表
- ✅ 客戶端富文本顯示含 XSS 安全防護

**技術實作：**
- 前端：ReactQuill WYSIWYG 編輯器
- 安全：DOMPurify HTML 淨化
- 後端：MongoDB images 陣列儲存
- UI：拖曳排序、圖片預覽

**影響範圍：**
